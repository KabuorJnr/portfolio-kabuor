# Rooney Odhiambo · 3D Gallery & Full-Stack Systems Portfolio

An immersive 3D gallery and comprehensive systems architecture portfolio built with **Three.js (r128)**, featuring **15 flagship exhibits** across 3D walls and central display plinths, plus a rich, scrollable **"Read as Page"** systems catalog covering **25+ production builds, active pilots, and open-source tools**.

## Key Systems Featured
1. **VeriBid** (`veribid.app`): Cryptographic sealed-bid public procurement with AES-256 encrypted bids, append-only SHA-256 audit chain guarded by MySQL triggers, and Power BI Embedded analytics.
2. **Kabuor ERP** (`kabuor-erp.onrender.com`): Central enterprise operating brain for Kenyan business. Real-time M-Pesa Till & Paybill auto-reconciliation, KRA eTIMS QR tax invoicing, 3-way procurement matching (PO ↔ GRN ↔ Invoice), and automated statutory payroll (PAYE, NSSF Tier I/II, SHA, Housing Levy).
3. **BloodBridge**: Coast Regional Blood Transfusion Center (RBTC) inventory, RSL-MODA emergency drone dispatch, IoT cold-chain temperature telemetry (2°C–6°C), and national FHIR/DHIS2 reporting.
4. **BuildFlow Field & API**: Offline-first civil engineering inspection suite for remote construction sites using Expo, WatermelonDB, SQLite, and an asynchronous FastAPI backend with Supavisor pooling.
5. **EduOne / DigiShule** (`edu1app.tech`): Offline-first Kenyan Competency-Based Curriculum (CBC) school ERP with IndexedDB caching, Capacitor Android APK, automated parent SMS alerts, and M-Pesa fee collection.
6. **Microsoft Fabric Medallion Lakehouse**: Dynamics 365 ERP and Dataverse ingestion across Bronze, Silver, and Gold star schemas with PySpark, Delta Lake Z-Ordering, and Power BI Direct Lake mode sub-second queries.
7. **BlueProof**: Coastal mangrove climate MRV using Sentinel-2 NDVI satellite imagery, geotagged smartphone photo verification, deterministic GPS gates, and automated M-Pesa B2C payouts with an immutable payout ledger.
8. **Northwind Executive Dashboard**: 4-page Power BI executive suite versioned natively in Git as code (PBIP with TMDL semantic models and PBIR visual layouts) with 50 DAX measures.
9. **SmartStock POS** (`inventory-ms-delta.vercel.app`): Hardware and retail POS with camera barcode scanner, live KRA eTIMS fiscal invoices, and M-Pesa SMS auto-reconciliation.
10. **Kabuor Builds** (`kabuor-builds.vercel.app`): Multi-tenant merchant e-commerce engine with live preview and direct Till/Paybill checkout.
11. **Japheth Sys**: Public works contract manager, milestone tracking, and 10% retention sum escrow accounting.
12. **Transparent Tenders Kenya** (`ttk-six.vercel.app`): Fraud detection heuristics for public procurement (collusion, cartel rings, price inflation) with a public SHA-256 audit ledger.
13. **ChamaOne** (`chama-one-ten.vercel.app`): SACCO and table banking mobile manager with automated M-Pesa STK push contribution reconciliation and in-app loan voting.
14. **Specialized & Civic Systems**: Stadi, Tikiti, Finance Bill 2026, AXIOM Financial Intelligence Bot, CentrSocial, ComradeConnect, Embossed Cards, Mkurugenzi, Bella Apartments, JoraTech, and Tracy Abega Portfolio.

## Features
- **3D Walk-in Exhibition**: Plaster walls, dark oak floorboards, recessed gallery spotlights, automatic sliding glass doors, and bespoke procedural artistic canvas motifs.
- **Interactive Mini-Map Radar**: Real-time room map showing visitor position, field-of-view sight cone, and colored exhibit blips with 1-click teleportation.
- **Mobile Touch Walk Controls**: Floating D-pad for mobile and tablet visitors.
- **Interactive Systems Matrix**: Real-time search and category filter pills (`All`, `GovTech`, `ERP & Commerce`, `Data Engineering`, `Health & Climate`, `Fintech`, `EdTech`).
- **Direct 3D Bridge**: "View in 3D 🏛️" buttons on all project cards glide the camera straight to that exhibit in the 3D gallery.
- **Procedural Synthesizer Ambiance**: Subtle Web Audio museum acoustic drone toggleable from the top navigation bar.

## Run Locally
Double-click `index.html` directly in any web browser, or serve the directory:

```bash
npx serve .
```

## Deploy on Vercel / Netlify / Render
- **Framework Preset**: Other / Static HTML
- **Build Command**: None
- **Publish Directory**: `.` (Root)
